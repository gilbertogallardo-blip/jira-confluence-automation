# Validation Rules for Walkthrough Files

1. Required structure: every walkthrough file must include a top-level heading and a clear introduction.
2. Summary section: every walkthrough file must contain a `## Summary` section that briefly explains the lesson, deliverable, or outcome.
3. Quiz section: every walkthrough file must contain a `## Quiz` section with at least three quiz questions or prompts.
4. Content completeness: each section should include substantive content, not placeholders like `TODO`, `TBD`, or empty headings.
5. Formatting consistency: headings should use a consistent markdown structure, and lists/items should be clearly separated and readable.
6. File relevance: if the file is a walkthrough or training module file, it should match the module topic and include learning content aligned to the subject matter.
