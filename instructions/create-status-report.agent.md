# Create Status Report

Generate a weekly status report in Markdown.

Requirements:
- Use only Markdown headings and bullet points.
- Include these sections in order: Accomplishments, Blockers, Next Week.
- Use bullet points only within each section.
- Keep the total output to a maximum of 20 lines.
- Maintain a professional tone.
- Avoid fluff words, marketing language, and filler text.
- Keep the content factual, concise, and direct.

Output format:
## Accomplishments
- ...

## Blockers
- ...

## Next Week
- ...
